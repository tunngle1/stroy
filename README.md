# СтройАутсорс — сайт stroyautsors.ru

Статическая вёрстка по ТЗ от 21.11.2026. Фирменный стиль: navy #0B1F3A / lime #B6FF00 / white,
знак 2×2 с ведущим верхне-правым модулем (геометрия из утверждённого SVG брендбука).

## Структура

```
build.py                  — генератор страниц (обёртка header/footer + фрагменты)
site_src/pages/*.html     — контент страниц (фрагменты <main>)
site/                     — ГОТОВЫЙ САЙТ (заливается на хостинг целиком)
  index.html              — главная
  raznorabochie-na-stroyku/  dlya-chastnyh-lic/  srochno/  uborka-snega/
  ceny/  kak-rabotaem/  kontakty/
  politika-personalnyh-dannyh/  soglasie-klienta/  soglasie-soiskatelya/
  404.html  robots.txt  sitemap.xml  .htaccess  favicon.svg  send.php
  assets/ (css, js, fonts, img)
```

## Как редактировать

- Тексты/структура страниц → правьте `site_src/pages/<имя>.html`, затем `python build.py`.
- Дизайн (цвета, размеры) → `site/assets/css/style.css` (токены в `:root`).
- Шрифт и телефон/email → grep по `site/` (телефон в шапке/футере — в `build.py`,
  в index.html — вручную; после правки index.html тоже можно вынести через build.py).

## Деплой (Timeweb)

1. Залить содержимое `site/` в корень домена stroyautsors.ru (public_html).
2. Включить SSL (бесплатный Let's Encrypt в панели Timeweb).
3. Раскомментировать HTTPS-редирект в `.htaccess` после проверки SSL.
4. `send.php` шлёт заявки на info@stroyautsors.ru через `mail()`. Если письма не доходят —
   в панели Timeweb настроить SMTP для доменной почты (Яндекс 360) или заменить транспорт
   на PHPMailer + SMTP. Заявки также дублируются в `site/data/leads.jsonl` (закрыто .htaccess).

## Что НЕ сделано (по ТЗ — осознанно)

- Страница «Работа у нас» — набор через сайт не запускается, страница не публикуется
  (согласие соискателя сохранено как документ на случай запуска).
- Аналитика/Метрика/cookie-баннер — не подключены (нет законного решения на старте).
- Калькулятор, CRM, UIS-интеграция, онлайн-оплата — не требуются на первом этапе.
- Реальных фото объектов нет — визуал собран на фирменной графике (модули, сетки).

## Важно перед публикацией

- Сверить реквизиты (ОГРН/адрес) с выпиской ЕГРЮЛ — в ТЗ указано расхождение версий.
- Утвердить тексты политики и согласий с ответственным/юристом (в ТЗ — «проект»).
- Подтвердить операционные обещания (сроки, «от N человек») либо убрать с сайта.
